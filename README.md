# Chore Rotation for Home Assistant

A deterministic household-chore scheduler. It **does not send notifications** or require a calendar. A read-only sensor publishes a map of each person to their chores for the current day. Use normal Home Assistant automations to consume it.

## Installation

This is an installable **custom integration** repository, ready to publish as a GitHub repository for the Home Assistant Marketplace (HACS). To install it, upload this directory to your own public GitHub repository, add that repository as a custom integration in the Marketplace, install, and restart Home Assistant. Alternatively, copy `custom_components/chore_rotation` into `<config>/custom_components/` and restart HA.

Add **Chore Rotation** in **Settings → Devices & services → Add integration**. It starts with the chore list discussed and two placeholder people.

## Management interface

Open **Settings → Devices & services → Chore Rotation → Configure** to:

- Add, rename, or delete people.
- Add, edit, or delete chores.
- Change a chore's frequency and position within its frequency group.
- Configure an ordered cyclic assignment sequence, using comma-separated person names. For example, `Person A, Person A, Person A, Person A, Person A, Person A, Person B` gives a 6/7 split with B on Sunday for daily chores. `Person A, Person B` alternates each occurrence, even for weekly/monthly chores.

Each save closes the configuration dialog and applies the new configuration. Reopen **Configure** to make another change. A person referenced by any task cannot be deleted until those assignments are changed.

## Output entity

The sensor is named **Chore Rotation Today**, usually `sensor.chore_rotation_today`. The numerical sensor state is the number of chores scheduled today. Attributes contain:

```yaml
date: "2026-11-22"
assignments:
  Person A:
    - Einkaufen
    - Spülmaschine einräumen
  Person B:
    - Kochen
    - Küche saubermachen
```

The mapping above illustrates the *format*, not a guaranteed list for that date.

To read the list for a person from an automation template:

```jinja2
{{ state_attr('sensor.chore_rotation_today', 'assignments').get('Person A', []) }}
```

For notifications, create a **time-triggered automation** that reads this attribute and calls the mobile-app notification action. No notifications are generated by the integration. The sensor updates at midnight and is immediately recomputed after a restart or configuration change. If HA was offline, earlier days are ignored.

## Scheduling rules

- Tasks are selected in their configured order within the five frequency groups: daily, twice weekly, weekly, monthly, quarterly.
- Each daily chore occurs once each day; each twice-weekly chore twice per Monday–Sunday week; weekly chores once each week; monthly chores once per calendar month; quarterly chores once per calendar quarter.
- Required task occurrences are spread across the available days by integer partitioning, with multiple occurrences on one day when necessary.
- Assignment cycles are independent **per task**, not reset at period boundaries. The result is computed from the date, with no volatile counters or replay.
- No load balancing, acknowledgement/completion tracking, or overdue-task handling.

**Note:** Editing task order, frequency or cycle changes date-derived assignments, including historical results if recalculated. The configuration is persisted in HA's config entries, and no historical audit log is kept. Assignment cycles are anchored to the Monday **2026-11-16**. A recurring daily 6/7 `A,A,A,A,A,A,B` cycle therefore places B on Sundays.
